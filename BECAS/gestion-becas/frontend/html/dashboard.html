AYUDA

Preguntas frecuentes

Encuentra respuestas a las preguntas más comunes sobre las becas.

¿Qué es ScholarLink?

ScholarLink es una plataforma diseñada para facilitar la búsqueda y gestión de oportunidades de becas educativas.

¿Cómo puedo solicitar una beca?

Primero debes seleccionar una convocatoria, revisar sus requisitos y posteriormente completar el proceso de postulación.

¿Puedo aplicar a más de una beca?

Sí. Puedes consultar diferentes convocatorias y aplicar a aquellas para las que cumplas con los requisitos.

¿Dónde puedo consultar los requisitos?

Puedes consultar los requisitos generales en esta sección y revisar los requisitos específicos dentro de cada convocatoria.

¿Cómo sé si mi solicitud fue enviada?

Una vez completado correctamente el proceso de postulación, recibirás la confirmación correspondiente de tu solicitud.
